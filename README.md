# smart-lens-search-plugin
Select any area on a webpage and instantly search it with Google or ChatGPT.
# Smart Lens Search

一个用于网页区域选择与 AI 搜索的 Chrome 扩展。

支持：

- Google 搜索
- ChatGPT 搜索
- 快捷键调用
- 任意网页区域截图选择
- chrome请自行登录ChatGPT和Google账号
- 本插件无需登录、无需上传数据、无隐私收集。

------------------------------------------
 
# 安装方法：
1. 下载 AIplugin.zip
2. 解压到任意目录
3. 打开 chrome://extensions/
4. 打开开发者模式
5. 点击“加载已解压的扩展程序”
6. 选择 AIplugin 文件夹
7. 安装完成
